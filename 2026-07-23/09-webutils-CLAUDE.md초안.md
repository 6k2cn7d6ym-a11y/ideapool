## 8. 자율협업 종결 규칙

자율지시 세션은 자율협업 방. 팀장·대리·사원이 자기 권한 안에서만 발언.

**마커 사용 순서**
1. 파일 저장 완료 확인
2. `[[기록: 완료 | 구체 내용]]` (방 완전 종료 시) 또는 `[[자율 지시: 세션이름 | 다음사람 요청]]` (릴레이 시)
3. `[[자율종결]]`

**릴레이 vs 방 종료**
- **릴레이 진행** (방 아직 안 끝남): `[[자율 지시: ... 요청]]` → `[[자율종결]]`
- **방 완전 종료** (최종 확정): `[[기록: 완료 | ...]]` → `[[자율종결]]`
- **판단 불가**: `[[결재: 담당팀 | 제목]]` (자율종결 안 함 · 대표 결재 대기)

**금지 사항**
- 파일 저장 전 `[[자율종결]]` 배치
- 릴레이 시 `[[기록: 진행중]]` 사용 (릴레이 마커가 방 상태 신호)
- 상대 페르소나 대필 (사원이 팀장 발언 부착 등)
- "대표님 확인 필요"로 판단 미루기 → `[[결재: ... ]]` 사용

## 13. AI 직원이 작업할 때 주의사항

1. **자율지시 세션은 자기 페르소나만 수행** — 상대 대필 절대 금지
2. **파일 상태 기반 자기 역할 판단** — 세션 진입 시 파일 마지막 상태 확인
3. **마커 순서 엄수** — 저장 → 기록/릴레이 → 자율종결
4. **판단 불가 시 결재 상신** — "대표님 확인 필요"로 대체 금지
5. **커밋 메시지**: `{작업 유형}: {유틸 이름 또는 세션 요약}`
6. **아이디어샘물 관련 작업 개입 금지** — 이 프로젝트는 웹유틸 전용
