## 1. 커스텀 도메인 붙이기 (`utils.minon.kr`)

Cloudflare Pages 대시보드에서:

1. `webutils` 프로젝트 → **Custom domains** 탭 → **Set up a custom domain**
2. `utils.minon.kr` 입력 → **Continue**
3. Cloudflare가 DNS 설정 값을 안내:
   - **minon.kr이 Cloudflare 네임서버를 쓰는 경우** → 자동 추가 (한 번 클릭)
   - **외부 등록기관(가비아·후이즈 등)을 쓰는 경우** → 안내된 CNAME 값을 해당 콘솔에서 수동 추가
     - 유형: `CNAME`
     - 이름: `utils`
     - 값: (Cloudflare가 안내한 도메인, 보통 `webutils-d4h.pages.dev`)
4. SSL 자동 발급 대기 (10분~1시간)
5. 브라우저에서 `https://utils.minon.kr` 접속 확인

## 4. 첫 파일럿 후보 (참모 참고 의견)

대표 예시는 "날짜 변환기"였으나 SEO 관점에서 재검토 권고:

| 후보 | 예상 검색량 | 경쟁 | 참모 코멘트 |
|---|---|---|---|
| 날짜 계산기 (D-day류) | 30K~50K/월 | 포화 | 진입 어려움 |
| **만나이 계산기** | 40K~80K/월 | 중 | 2023 만나이 통일법 이후 검색 상승세. 유리 |
| **평 ↔ ㎡ 변환기** | 20K~30K/월 | 낮음 | 부동산 관련. 광고 단가 유리 |
| **카카오톡 이모티콘 코드** | 10K~20K/월 | 낮음 | 사이트 부족. 공백 유리 |

**참모 권고:** 첫 파일럿은 위 자율지시 `webutils-SEO스코어` 세션에서 정식으로 결정. 개인 감이 아니라 팀 스코어링으로 확정하는 게 재현성 있음. 급하시면 **"만나이 계산기"**로 강제 지정도 가능.
